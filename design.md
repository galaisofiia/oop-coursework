# Задача 0: проектирование структуры

## Структура проекта
- src/models: классы данных (contact, phone)
- src/services: бизнес-логика и валидация (validator)
- src/storage: работа с хранилищами (istorage, filestorage, dbstorage)
- src/ui: графический интерфейс (mainwindow, contactform)
- tests: юнит-тесты

## Назначение классов
- phone: хранение и валидация одного телефонного номера. форматирует номер к единому виду
- contact: агрегация всех полей контакта (имя, фамилия, email, телефоны, дата рождения). отвечает за проверку обязательных полей
- validator: статические методы для проверки строк и дат через регулярные выражения
- istorage: абстрактный интерфейс для работы с хранилищем (добавление, удаление, сохранение, загрузка)
- filestorage: реализация интерфейса istorage для сохранения данных в json файл
- dbstorage: реализация интерфейса istorage для работы с postgresql
- contactmanager: управление списком контактов, поиск и сортировка. Этот класс связывает ui и хранилище
